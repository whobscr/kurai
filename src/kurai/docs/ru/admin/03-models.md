# Модели

Курай работает и без модели; модель даёт названия и описания плейлистов, «Спросить» и «Почему этот трек».

## Поставщики

| Поставщик | Для чего |
|---|---|
| OpenAI-совместимый | llama.cpp, vLLM, OpenAI, OpenRouter, LM Studio. Выберите «тип сервера»: у них немного разные параметры |
| Ollama | через её собственный API — так задаётся длина контекста и длинные запросы не обрезаются |
| Claude | через официальный SDK Anthropic; модель по умолчанию — claude-opus-5-5 |

**Эмбеддинги** настраиваются отдельно: у Claude их нет. Смена модели эмбеддингов переиндексирует библиотеку ночью — векторы разных моделей несравнимы.

## «Модель думает»

Переключатель для каждой задачи. Размышление заметно улучшает ответы, но на процессоре добавляет минуты. По умолчанию включено для ночных задач и выключено там, где ждёт человек. Рядом показано, сколько задача обычно занимает с размышлением и без.

## Параллельные запросы

«Параллельные запросы к модели» — сколько запросов Курай отправляет одновременно (по умолчанию 2). Сам сервер llama.cpp принимает столько, сколько у него слотов (`--parallel`); лишние просто ждут в его очереди.

## Конфиденциальность

Облачная модель получает с каждым запросом вкусы слушателей и названия из библиотеки.
