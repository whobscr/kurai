# Первый запуск

1. **Войдите** как admin / admin и задайте пароль. Он же станет вашим паролем в музыкальных приложениях.
2. **Модели**: проверьте адреса модели для текста и модели эмбеддингов кнопками «Проверить».
3. **Пользователи**: добавьте остальных (регистрации нет — только администратор добавляет людей).
4. **Звук** (по желанию): включите анализ звука, если запущен контейнер `audio`.
5. **Общие → Открытые данные о музыке** (желательно): токен ListenBrainz. С ним Курай узнаёт, что в мире слушают больше всего из вашей библиотеки, — с этого «Моя волна» начинается у новых слушателей.

Ночью Курай проиндексирует библиотеку, а когда появятся прослушивания — предложит первые миксы. Дальше всё идёт само: ночью — вкусы и миксы.

## Картинки {#art}

Вкладка «Общие» → «Оформление по умолчанию». На карточке «Моей волны» и в шапке страниц — картинки о музыке; они сменяют друг друга сами: картинка «Моей волны» по умолчанию раз в час, картинка шапки — раз в сутки (в полночь по времени сервера). В одно и то же время у всех на всех страницах одна и та же картинка; за круг показывается каждая, в новом порядке каждый круг. Можно задать дробные часы: 0,5 — раз в полчаса.

## Ночное окно {#night}

Вкладка «Общие»: когда идёт тяжёлая работа (по умолчанию 06:00–10:00). Задачи, которые ждёт человек («Спросить»), выполняются в любое время.

## Открытые данные о музыке {#public-data}

Вкладка «Общие». **ListenBrainz** — открытая статистика прослушиваний: раз в 3 часа Курай спрашивает у него, сколько слушают альбомы исполнителей из вашей библиотеки (до 150 исполнителей за раз, каждого — раз в месяц; задача `popularity`, кнопка «Популярность (ListenBrainz)» на «Задачах»). Нужны идентификаторы MusicBrainz в тегах файлов — исполнители без них не учитываются. Пока никто на сервере ничего не слушал, «популярное» в «Моей волне» берётся отсюда.

Если в тегах файлов нет идентификаторов MusicBrainz (частый случай для музыки не из MusicBrainz Picard), Курай сам ищет их в MusicBrainz: по имени исполнителя и названиям его треков — так различаются разные исполнители с одним именем; файлы не меняются. До 100 исполнителей за раз, раз в 3 часа и ночью (задача `artist_ids`, кнопка «Идентификаторы исполнителей (MusicBrainz)» на «Задачах»); не найденного спрашивает снова через месяц. Идентификатор из тегов всегда главнее найденного.

Токен бесплатный: войдите на listenbrainz.org (учётная запись MusicBrainz) → Settings → «User token». **MusicBrainz** — каталог с тегами исполнителей; он просит указывать в запросах контакт (e-mail или сайт). Проверка — кнопки «Проверить ListenBrainz» и «Проверить MusicBrainz»; сеть — на вкладке «Шлюз». MusicBrainz там отдельной галочкой: он бывает недоступен через одни прокси и доступен через другие.
