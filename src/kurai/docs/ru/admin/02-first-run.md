# Первый запуск

1. **Войдите** как admin / admin и задайте пароль. Он же станет вашим паролем в музыкальных приложениях.
2. **Модели**: проверьте адреса модели для текста и модели эмбеддингов кнопками «Проверить».
3. **Пользователи**: добавьте остальных (регистрации нет — только администратор добавляет людей).
4. **Звук** (по желанию): включите анализ звука, если запущен контейнер `audio`.

Ночью Kurai проиндексирует библиотеку, а когда появятся прослушивания — предложит первые миксы. Дальше всё идёт само: ночью — вкусы и миксы.

## Ночное окно {#night}

Вкладка «Общие»: когда идёт тяжёлая работа (по умолчанию 06:00–10:00). Задачи, которые ждёт человек («Спросить»), выполняются в любое время.
