# Приложения, плагины и резервные копии

## Приложения {#apps}

Вкладка «Приложения» открывает страницы администратора приложений, работающих рядом с Kurai, прямо в Kurai — через его вход, без отдельного пароля. Значок ⓘ рядом с кнопками коротко говорит, зачем нужно выбранное приложение и что оно делает в системе. Как они связаны между собой — в разделе [«Устройство системы»](/docs/admin/architecture). Если окно мало, «На весь экран» разворачивает приложение на весь экран (вернуться — «Свернуть» в углу или Esc; на iPhone браузер так не умеет), а «Открыть в новой вкладке» открывает его отдельно. Снаружи они недоступны; прямой доступ к их API — через SSH с пробросом порта.

### Navidrome {#navidrome}

Музыкальный сервер, на котором стоит Kurai. Он:

- хранит и сканирует библиотеку — папку `$KURAI_DIR/data/music` (новые файлы замечает сам, раз в час);
- отдаёт музыку плеерам по протоколу Subsonic — к нему подключаются Symfonium, Feishin, Amperfy и другие;
- записывает, что и сколько раз слушали, звёзды и оценки.

Kurai читает из него библиотеку и прослушивания, а свои плейлисты (ночные миксы, «Моя волна», «Спросить») записывает обратно — так они появляются в любом плеере. Пользователи и пароли заводятся в Kurai и переносятся в Navidrome сами. В самой админке Navidrome бывает нужно: запустить сканирование, посмотреть библиотеки, настроить транскодирование и общие плейлисты.

Плагины могут добавить свои приложения; их описание — в ⓘ и в справке плагина.

## Плагины {#plugins}

Вкладка «Плагины» показывает установленные плагины — дополнительные части Kurai — с переключателем у каждого. Выключенный плагин пропадает из меню, настроек и задач; его настройки и данные остаются, а его задачи в очереди ждут, пока его не включат снова. После сохранения Kurai перезапускается сам: страницу можно обновить через полминуты.

## Резервные копии

Kurai сам копий не делает. Нужно сохранять:

- базу PostgreSQL (`pg_dump -Fc kurai`);
- папку настроек Navidrome (`$KURAI_DIR/config/navidrome`), без журналов и кэшей;
- саму музыку (`$KURAI_DIR/data/music`).

Пример — в README репозитория.
