# Приложения и резервные копии

## Приложения

Вкладка «Приложения» открывает страницу администратора Navidrome прямо в Kurai — через его вход, без отдельного пароля. Снаружи они недоступны; прямой доступ к их API — через SSH с пробросом порта.

## Резервные копии

Kurai сам копий не делает. Нужно сохранять:

- базу PostgreSQL (`pg_dump -Fc kurai`);
- папку настроек Navidrome (`$KURAI_DIR/config/navidrome`), без журналов и кэшей;
- саму музыку (`$KURAI_DIR/data/music`).

Пример — в README репозитория.
