# Пользователи

Регистрации нет: людей добавляет администратор («Пользователи» → «Новый пользователь»). У каждого — своя учётная запись Курая и такая же в Navidrome (для музыкальных приложений), своя история, вкусы и плейлисты.

- **Роли**: администратор и пользователь. Системные настройки — только у администраторов. Последнего администратора нельзя понизить или отключить.
- **Пароль**: «Задать пароль» — пользователь сменит его при следующем входе; все его открытые сеансы закрываются.
- **Подбор пароля**: после 5 неверных попыток с одного адреса (или 20 с любых) вход под этим именем закрыт на 15 минут; после 5 неверных кодов двухфакторного входа пароль нужно ввести заново.
- **Двухфакторный вход**: «Сбросить 2FA», если человек потерял телефон и резервные коды. С сервера: `docker compose exec web kurai reset-2fa <имя>`.
- Забыли пароль администратора: `docker compose exec web kurai reset-password <имя>` выдаст временный.
