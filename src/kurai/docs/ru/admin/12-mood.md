# Настроение (тень и влияние)

Волна считает настроение сессии по **принятым** трекам (валентность и энергия из анализа звука). Пропуски в
оценке настроения не участвуют: пропуск может означать не тот трек, не того исполнителя, не тот момент — и не
обязательно «не нравится».

Сначала — только тень. Настроение, уверенность и проверка видимы в «Задачах», на выбор треков не влияют.
Проверка отвечает на вопрос: дослушанные треки в среднем ближе к настроению сессии, чем пропущенные?

Включать «Учитывать настроение» стоит только когда проверка стабильно проходит. Тогда кандидаты получают
поправку «Влияние настроения» (в разбросах, как прочие поправки), ограниченную этим значением; треки без анализа
звука получают 0 и не штрафуются. На «плохом дне» (много пропусков, мало принятых) поправка не применяется вовсе.

Настроение не меняет постоянный вкус.
