# Шлюз: прокси для всех исходящих соединений

Один прокси на всё приложение и галочка для каждой подсистемы: Telegram, облачные модели, push-уведомления, загрузка моделей анализа звука, ListenBrainz и MusicBrainz. С галочкой подсистема ходит **только** через прокси: если он недоступен, она сообщает об ошибке, а не идёт напрямую.

- **Прокси**: `socks5h://host:port` (имена разрешает прокси — обычно лучший вариант), `socks5://…` или `http://…`; логин и пароль — по желанию.
- **DNS-сервер**: IP-адрес (`10.8.0.1`, `10.8.0.1:5353`, `[fd00::1]:53`) — для VPN, чей DNS отдаёт адреса внутри туннеля. С `socks5h` не нужен. Если он не отвечает, Курай не переходит на системный DNS. Claude и push-уведомления этот DNS не используют (их библиотеки берут DNS системы) — для них выбирайте `socks5h`.
- **Проверить** — у каждой подсистемы: один настоящий запрос через её путь, время или текст ошибки.

Navidrome берёт прокси только из переменных окружения контейнера.

Входящие соединения (сайт, музыкальные приложения) через шлюз не идут.
