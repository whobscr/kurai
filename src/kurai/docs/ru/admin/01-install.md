# Установка

Курай запускается одним `docker compose`: веб-приложение, фоновые задачи, Navidrome (плеер) и, по желанию, база данных, модели и анализ звука.

```sh
git clone https://github.com/whobscr/kurai && cd kurai
cp .env.example .env        # заполните KURAI_SECRET_KEY, пароль базы, папку данных
docker compose up -d
```

Профили (`COMPOSE_PROFILES` в `.env`):

| Профиль | Что добавляет |
|---|---|
| `db` | PostgreSQL с pgvector (если своей базы нет) |
| `cpu` | llama.cpp на процессоре: модель для текста и модель эмбеддингов |
| `gpu` | то же на видеокарте NVIDIA |
| `audio` | анализ звука (см. «Анализ звука») |

Без `cpu`/`gpu` укажите в настройках внешний сервер моделей или облачный API.

Музыка лежит в `$KURAI_DIR/data/music` (по папке на исполнителя или как угодно — Navidrome читает теги). Navidrome сам замечает новые файлы.

Первый вход: **admin / admin**, пароль сразу нужно сменить.
