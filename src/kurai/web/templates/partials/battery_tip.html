{# Android phones' battery savers (Samsung, Xiaomi…) put the browser to sleep with the screen off, and the music stops; the same text in the one-time window on a phone (base.html) and in «Кабинет → Приложение на телефоне» #}

{{ _("На многих телефонах Android (Samsung, Xiaomi и других) экономия батареи усыпляет браузер, когда экран выключен, — и музыка останавливается, обычно между треками. Курай тут ничего не может сделать сам: нужно разрешить браузеру работать в фоне.") }}

  1. {{ _("«Настройки» → «Приложения» → Chrome (или другой браузер, из которого установлен Курай) → «Батарея» → «Без ограничений».") }}
  2. {{ _("Samsung: ещё «Настройки» → «Батарея» → «Ограничения фонового использования» — браузера не должно быть в «Спящих приложениях» и «Приложениях в глубоком сне».") }}
  3. {{ _("Xiaomi, Redmi, POCO: «Настройки» → «Приложения» → Chrome → «Контроль активности» → «Нет ограничений».") }}

{{ _("Названия пунктов немного отличаются от модели к модели. На iPhone этого делать не нужно.") }}
