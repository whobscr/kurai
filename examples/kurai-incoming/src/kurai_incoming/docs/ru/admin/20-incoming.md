# Входящие

Плагин-пример: альбомы, положенные в папку входящих, попадают в библиотеку после одобрения администратора.

1. **Система → Входящие**: проверьте папку (по умолчанию `/data/incoming`, то есть `$KURAI_DIR/data/incoming` на сервере) и нажмите «Проверить папку».
2. Положите альбом папкой «Исполнитель - Альбом». В течение получаса он появится в списке, а администраторы получат уведомление.
3. Нажмите ✓ — Kurai перенесёт папку в библиотеку, Navidrome найдёт её при следующем сканировании. ✕ — папка останется во входящих.

С переключателем «Переносить без одобрения» альбомы переносятся сразу. Если такой альбом в библиотеке уже есть, он остаётся во входящих с пометкой.

В Telegram-боте администратор может написать «входящие» — бот ответит, сколько альбомов ждут одобрения.
